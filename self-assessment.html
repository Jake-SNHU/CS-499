Professional Self-Assessment

Completing the Computer Science program and developing my ePortfolio has helped me strengthen the technical skills I use in my career as a control systems engineer integrating SCADA systems. I originally pursued this degree to better understand the computer science concepts behind the systems I work with. Throughout the program, I developed skills in software development, databases, algorithms, and secure coding that have expanded my abilities beyond controls and automation.

One of my strengths is being able to work across different technologies and understand how they interact. My coursework gave me experience with Java, C++, Python, JavaScript, SQL, SQLite, and MongoDB. I also worked with full-stack development using MongoDB, Express, Angular, and Node.js. These projects taught me how different components of a system work together and helped me become more comfortable learning new technologies.

Collaboration and Communication

My coursework also improved my ability to communicate technical information and work with different stakeholders. Software development requires more than writing functional code; requirements need to be understood and communicated clearly. My professional experience with SCADA and control systems has reinforced this because I regularly work with people who have different technical backgrounds. I have learned to focus not only on whether a solution works, but also on whether it can be understood, maintained, and used effectively.

Algorithms and Data Structures

The program strengthened my understanding of algorithms and data structures. I learned to consider efficiency and the problem being solved rather than simply writing code that produces the correct result. For my capstone Android application, I implemented binary search, sorting by event name, date, and time, event searching, and more efficient RecyclerView updates. These enhancements helped me see how algorithmic concepts directly affect application performance and usability.

Software Engineering and Databases

My software engineering coursework taught me that quality software must be maintainable, secure, and adaptable. My work with legacy code and C++ also taught me how to analyze existing software and identify potential vulnerabilities.

I gained database experience with both SQLite and MongoDB. In my Android application, I implemented CRUD operations for events and improved database validation and password security. My MongoDB project included a Python CRUD module and an interactive dashboard that allows users to filter animal records, view breed information, and display animal locations on a map. These projects helped me understand how databases support larger software systems.

Security

Security became an important part of how I approach development. My secure coding coursework taught me to consider vulnerabilities during the development process instead of waiting until testing. In my Android application, for example, I replaced plain-text password storage with SHA-256 hashing and added input validation. My work with legacy code also helped me understand vulnerabilities such as improper input handling and buffer overflows.

How My Artifacts Fit Together

The three artifacts in my ePortfolio demonstrate different areas of my computer science development.

The Software Design and Engineering artifact is my Android Event Tracker application. Its enhancements demonstrate my ability to improve an existing application through better organization, validation, security, and maintainability.

The Algorithms and Data Structures artifact builds on the same application by adding binary search, sorting, searching, editing, and more efficient RecyclerView updates. This demonstrates my ability to apply algorithms to a practical software system.

The Database artifact is my MongoDB Animal Shelter dashboard. It demonstrates CRUD operations, database integration, filtering, data visualization, and geolocation.

Together, these artifacts demonstrate my ability to develop software, work with databases, apply algorithms, and consider security throughout the development process. They also show how my Computer Science education complements my existing experience in control systems and SCADA integration.

Overall, the program has given me a stronger understanding of the technology behind the systems I work with and increased my ability to approach technical problems from both a controls and software perspective. My ePortfolio demonstrates not only what I have learned, but also my ability to evaluate existing systems and continuously improve them.
